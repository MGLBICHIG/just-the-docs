# 贴纸

贴纸[^label]是文档中标记文字的一种附加方式。贴纸通常会配以特殊颜色，默认为蓝色。

[^label]: label 常用翻译为标签，这里翻译为贴纸，类似冰箱贴的一种文字标识。之所以这么翻译，是为了同 Tag（标签）区别开，所以叫做贴纸。

<div class="code-example" markdown="1">

{: .label }

蓝色贴纸
{: .label .label-blue }

稳定
{: .label .label-green }

新版
{: .label .label-purple }

{: .label .label-yellow }

弃用
{: .label .label-red }
